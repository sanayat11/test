# Тестовое задание: Мини-карточка лида для CRM

Простая веб-страница для добавления лидов в CRM. Реализовано на чистых HTML, CSS и JavaScript без использования сторонних фреймворков и библиотек.

## Что реализовано:
- Форма добавления лида со всеми требуемыми полями.
- Валидация обязательных полей (имя и телефон) с подсветкой и сообщениями об ошибках.
- Сохранение лидов в `localStorage` (данные не теряются после обновления страницы).
- Отображение списка сохраненных лидов в виде карточек.
- Изменение этапа сделки по циклу (Новый лид -> Квалифицирован -> Назначена консультация -> Отказ -> Новый лид).
- Удаление лида (с подтверждением).
- Счетчик количества лидов.
- Безопасное отображение данных (защита от XSS-уязвимостей).
- Защита от двойной отправки формы и поддержка отправки по нажатию клавиши Enter (встроено в браузерную работу форм).
- Адаптивный дизайн.

## Как запустить проект:
1. Клонируйте репозиторий или просто откройте папку проекта.
2. Дважды кликните по файлу `index.html`, он откроется в любом современном браузере.
3. Проект полностью работает локально (backend, база данных, Docker не требуются).

## Где находится логика:
- **Интерфейс:** в файле `index.html` (форма, поля, область сообщений, область карточек лидов).
- **Стили:** в файле `style.css` (отступы, цвета, адаптивность).
- **Логика приложения:** в файле `script.js`.
  - Логика кнопки «Сохранить» (обработчик отправки формы): функция `handleFormSubmit(event)`
  - Валидация: функция `validateForm(name, phone)`
  - Сохранение в `localStorage`: функции `saveLeads()` и `loadLeads()`, ключ `crmLeads`
  - Создание нового лида: функция `createLead(name, phone)`
  - Отображение карточек лидов: функция `renderLeads()`
  - Изменение этапа сделки: функция `changeLeadStage(id)`

## Какие проверки стоит провести самостоятельно:
- Нажать «Сохранить» с пустой формой (ошибка, фокус на первое поле).
- Ввести только имя или только телефон (соответствующие ошибки).
- Успешное создание лида.
- Создание нескольких лидов.
- Обновление страницы (лиды должны остаться на месте).
- Изменение этапа сделки по кнопке в карточке, с последующим обновлением страницы (измененный этап должен сохраниться).
- Вставить HTML-теги (например `<img src=x onerror=alert(1)>`) в поле имени (данные должны вывестись как обычный текст благодаря `textContent`).
- Ручное повреждение `localStorage` через DevTools (приложение инициализирует пустой массив и не падает благодаря блоку `try/catch`).
